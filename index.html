Sabilearn: an AI study assistant that works offline

Students upload course PDFs or lectures, then ask questions and get quizzes, flashcards and study guides from their own material.

Team of five and a mentorPythonOllamaRAGChromaDB
Student messagequestion, quiz, flashcards or guide
Intentwhat do they want?

Course routerwhich course?
RetrievalChromaDB, filtered by course
Local LLMllama3.2:3b on Ollama
Outputanswer, quiz, cards, study guide

Outlined stages are the parts I built. Retrieval and generation come from the team’s RAG pipeline.

Problem

AI study tools usually depend on an internet connection and paid API keys. Sabilearn was built to run entirely on local, free models, so a student can study with AI with no connection and no cost per question.

My role

AI engineer on the Study Agent, the conversational layer on top of the team’s RAG pipeline. The pipeline handles retrieval and generation. The Study Agent decides what the student is asking for and which course it belongs to. I also built study guide generation from scratch. I had never used Ollama before this project.

How it works

Intent routing

Every message is classified as a question, a quiz, flashcards or a study guide before anything is retrieved, so one chat box handles all four.

student  flashcards for this
intent   flashcards
result   5 cards from the right course

Conversation memory

Follow-up questions are rewritten into standalone ones using the chat history, so retrieval searches for the real subject instead of a vague “it”.

turn 1   a Thermodynamics question about entropy
turn 2   Why does it increase?
rewrite  a standalone question about entropy
answer   grounded in the course PDF

Course routing

A JSON-mode call to the local llama3.2:3b model picks the course, so retrieval is filtered to the right material. If nothing matches, the agent asks the student to clarify.

student  (a Thermodynamics question)
route    thermodynamics

student  what is the capital of France?
route    no match: asks a clarifying question

Study guide generation

Pulls a broad slice of the course (top_k=15) and asks the model for a structured outline grounded in that material.

course   Thermodynamics
output   8 main topics
         subtopics under each
         a recommended study order
Challenges
  • Silent retrieval failure. The model returned the course in inconsistent casing, sometimes as its display name. Plain Q&A still worked, but quizzes, flashcards and guides quietly lost their course filter. I now normalize the value and validate it against real course IDs and names.
  • Lost keywords. Rewriting follow-ups before detecting intent stripped words like “quiz” from the message. Intent now reads the raw message, and the rewrite only supplies course context.
  • Handoff problems. One file was never committed, a dependency was missing, and requirements.txt had been saved in the wrong encoding. I fixed all three and confirmed the project runs after a fresh clone on a second machine.
Results
  • Team placed 2nd on the Week 3 bootcamp leaderboard.
  • 7-case test suite passing end to end for questions, quizzes, flashcards, study guides, unknown courses and off-topic messages.
  • Switched PDF parsing from pypdf to PyMuPDF to remove corrupted-object warnings, and tightened the tutor prompt for clearer answers.
Stack

Python, Ollama, llama3.2:3b, nomic-embed-text, ChromaDB. Plain Python functions, no agent framework.
